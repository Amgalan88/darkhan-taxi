## Яаж ажилладаг
Брэндийн нэр: **DMAP**. Газрын зураг үндсэн дэлгэц.

Зорчигч зөвхөн нийт үнэ хардаг. Төлбөр: **QPay** эсвэл **Жолооч бэлнээр авсан** (зорчигчид «бэлэн» товч байхгүй). Жолоочийн орлого = нийт − шимтгэл (анх 10%, админ өөрчилнө). Шимтгэл зөвхөн төлбөр батлагдсаны дараа: QPay дээр төлбөрөөс, «Бэлнээр авсан» дээр кредитээс. Дуусаагүй төлбөр дараагийн нэвтрэлтэд дахин гарна. Шинэ дуудлага тэр үед хаагдана. Кредит 0 бол шинэ дуудлага авахгүй.

Жолоочийн улсын дугаар заавал. Ойролцоох машинууд демо. Жолооч зөвшөөрсний дараа машин ойртож ирнэ.
