## Яаж ажилладаг
Газрын зураг үндсэн дэлгэц. Зорчигч очих цэгээ дарж дуудна. Ойролцоо машинууд демо хөдөлгөөнөөр харагдана. Жолооч зөвшөөрсний дараа машин авах цэг рүү ойртож ирнэ.

Жолооч бүртгэлд **машины дугаар** заавал. Зорчигч хүлээх үедээ дугаараа хардаг.

Төлбөр: зорчигч бэлэн сонгохгүй. Аялал дуусахад **QPay** (түлхүүргүй бол туршилтын бүртгэл), эсвэл жолооч **«Бэлнээр авсан»** дарж хаана. Зорчигчид суурь хураамж / комисс тусад нь харуулахгүй — зөвхөн нийт үнэ. Тарифыг админ засна (эхлэх үнэ + км).

Цуцлах: зорчигч дуудлага, ирж байх, ирсэн үед (хаахаас өмнө). Өгөгдлийн сан зөвхөн зорчигчид цуцлахыг зөвшөөрдөг тул жолоочид ажиллахгүй товч гаргахгүй.
