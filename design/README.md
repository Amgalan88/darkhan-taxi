# Дархан Такси — Зорчигчийн дэлгэцийн дизайн (390×844, @2x PNG)

Эх HTML/CSS: `src/` (`style.css` нийтлэг токен). Дахин рендер: `python3 render.py`.
Бүх үнэ, нэр, дугаар, газрын зураг нь **жишээ** — бодит өгөгдөл биш.

## Токен
### Өнгө (WCAG тодосгол, тооцоолсон)
| Нэр | Hex | Хослол | Харьцаа |
|---|---|---|---|
| navy | #0B2545 | цагаан дээр текст | 15.39:1 |
| yellow (CTA) | #FFC300 | navy текст | 9.57:1 |
| green (Залгах) | #16733A | цагаан текст | 5.92:1 |
| muted | #4A5568 | цагаан / #F4F6F9 / газрын зураг #E8ECE4 | 7.53 / 6.95 / 6.29:1 |
| bg | #F4F6F9 | navy текст | 14.21:1 |
| line | #D5DBE3 | зөвхөн хүрээ/чимэглэл | — |
Бүгд AA 4.5:1-ээс дээш.

### Үсэг — Inter (Cyrillic), fallback Noto Sans
- Гарчиг 28–32px / 800; Үнэ 40px / 800; Үндсэн CTA 26px / 800
- Талбар 20–24px / 600; Body **хамгийн багадаа 18px**; Тайлбар (зөвхөн "Жишээ" шошго) 13–14px

### Хэмжээ
- Tap target ≥ 56px (stepper 56×56, гар 56px); Талбар 64–80px; **Үндсэн CTA 72px**; хоёрдогч 60px
- Зай: 8 / 12 / 16 / 20 / 24px; дэлгэцийн хажуу 20–24px
- Radius: товч 18, карт 18, талбар 16, sheet 28 (дээд булан), товчлуур 10

## Дэлгэц тус бүр
1. **01-call** — CSS/SVG загварчилсан газрын зураг (tile татахгүй). Цэнхэр цэг + "Таны байршил" (Geolocation API). Доод sheet: "Хаашаа явах вэ?" талбар, урьдчилсан үнэ, "Өөрөө үнэ санал болгох" ± stepper (алхам ₮500 санал), "Дуудах" 72px.
2. **02b-phone → 02-login** — +976 тогтмол префикс, `inputmode="numeric"`, 8 орон. Код: 4 нүд (6 хүртэл өргөтгөж болно), `autocomplete="one-time-code"`, идэвхтэй нүд navy хүрээ. Дахин илгээх таймер.
3. **03-driver** — Машины тэмдэг + маршрут, ETA том гарчиг. Жолоочийн нэр, загвар/өнгө, улсын дугаар том хүрээтэй. "Залгах" ногоон (`tel:` холбоос), "Цуцлах" хүрээтэй хоёрдогч — баталгаажуулах цонх нээх.
4. **04-payment** — Аяллын хураангуй, QPay / Бэлнээр 80px radio карт (сонгосон нь шар дэвсгэр + navy хүрээ), "Төлбөр батлах".

Тэмдэглэл: emoji дүрсийг (📞 💵) бодит хэрэгжүүлэлтэд SVG icon-оор солих. Нэг дэлгэцэнд нэг гол үйлдэл.
