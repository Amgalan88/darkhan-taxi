# DMAP — Газрын зураг төвтэй UI бүрэн spec

Апп нэр (дэлгэц): **DMAP** (брэндинг батлагдах хүртэл). Зориулалт: Дархан хотын такси дуудлага, PWA.
Зорилтот хэрэглэгч: өндөр настан орно — цөөн товч, том touch target, өндөр тодосгол.
Бүх үнэ/нэр/дугаар жишээ биш бол жинхэнэ өгөгдөл; mock дээрх тоонууд жишээ.

## Токен
| Нэр | Hex | Хэрэглээ | Тодосгол |
|---|---|---|---|
| navy | `#0B2545` | текст, icon | цагаан дээр 15.39:1 |
| yellow CTA | `#FFC300` | гол товч | navy текст 9.57:1 |
| green call | `#16733A` | Залгах / Авах | цагаан 5.92:1 |
| danger | `#B42318` | Цуцлах баталгаа | цагаан дээр AA |
| muted | `#4A5568` | хоёрдогч текст | ≥6.29:1 |
| bg | `#F4F6F9` | sheet ар | — |
| map | `#E8ECE4` + SVG гудамж | бүтэн дэлгэцийн газрын зураг | tile татахгүй mock-д |

- Үсэг: Inter / Noto Sans (Cyrillic)
- Body ≥18px; гарчиг 28–32px/800; үнэ 40px/800; CTA текст 26px/800
- Tap ≥56px; талбар 64–80px; **гол CTA 72px**; хоёрдогч 60px
- Зай: 8/12/16/20/24; хажуу 20–24
- Radius: товч 18, карт 18, талбар 16, sheet дээд 28
- Газрын зураг: бүтэн дэлгэц. Sheet доор, цагаан, зөөлөн сүүдэр. Нэг дэлгэцэнд **нэг** гол үйлдэл.
- Icon: emoji биш SVG.

## Бизнес дүрэм (UI-д тусгах)
1. Зорчигчид зөвхөн **нийт үнэ**. Суурь/км/шимтгэл харуулахгүй.
2. Тариф (админ): суурь ₮3,000 + ₮1,000/км (солигддог).
3. Платформын орлого: аялал бүрээс **10%** (эхнээсээ).
4. Төлбөр: зөвхөн **QPay** эсвэл **Жолооч бэлнээр авсан**. Зорчигчид «бэлнээр» товч байхгүй.
5. QPay → 10% шууд суутгана. Бэлэн → жолоочийн **кредитээс** 10% хасна.
6. Кредит 0 бол жолооч шинэ дуудлага авч чадахгүй.
7. Жолоочийн машины дугаар **заавал**.
8. Аялал цуцлах боломжтой (батлах цонхтой).

## Зорчигч урсгал

### P0 Splash / нэвтрэх
- `02b-phone`: +976 тогтмол, 8 орон, `inputmode=numeric`, «Үргэлжлүүлэх» 72px.
- `02-login`: 4–6 нүд SMS код, `autocomplete=one-time-code`, дахин илгээх таймер.

### P1 Дуудах (`01-call`) — газрын зураг төв
- Дээр: цэнхэр цэг + «Таны байршил» (Geolocation).
- Ойролцоох боломжтой машинуудын жижиг тэмдэг (демо OK).
- Sheet:
  1. «Хаашаа явах вэ?» 64px талбар
  2. Очих газар сонгомогц **нийт үнэ** шууд (ж. ₮8,000)
  3. Сонголт: «Өөрөө үнэ санал болгох» ±₮500 stepper (хаах боломжтой)
  4. Шар «Дуудах» 72px

### P2 Хайж байна
- Sheet: «Жолооч хайж байна…» + эргэдэг индикатор
- «Цуцлах» хоёрдогч
- Газрын зурагт ойролцоох машинууд хөдөлгөөнтэй харагдана

### P3 Ирж байна (`03-driver`)
- Газрын зураг: маршрут + машинны тэмдэг хөдөлнө
- Sheet:
  - ETA том гарчиг («3 минутад ирнэ»)
  - Нэр, машины загвар/өнгө
  - **Улсын дугаар** том хүрээтэй (заавал)
  - Ногоон «Залгах» (`tel:`) 72px
  - «Цуцлах» → баталгаажуулах («Тийм, цуцлах» / «Буцах»)

### P4 Аялалд явж байна
- Газрын зурагт очих цэг хүртэлх маршрут
- Sheet: жолоочийн товч мэдээлэл + Залгах; доор «Очих газар» нэг мөр
- Цуцлах зөвхөн дүрмийн дагуу (эсвэл нуух)

### P5 Төлбөр (`04-payment`)
- Sheet: аяллын хураангуй + **нийт үнэ** том
- Хоёр том radio карт (80px): **QPay** / **Жолооч бэлнээр авсан**
- Сонгосон: шар дэвсгэр + navy хүрээ
- «Батлах» 72px
- Зорчигчид шимтгэл/бэлэн сонголт байхгүй

### P6 Дууссан / үнэлгээ
- Том «Баярлалаа»
- 1–5 од (56px tap)
- «Дуусгах» → P1

## Жолооч урсгал

### D0 Нэвтрэх + профайл
- Утас/SMS ижил
- Профайл: нэр, машинны загвар/өнгө, **улсын дугаар заавал** (хоосон бол «Авах» идэвхгүй)

### D1 Кредит
- Дээд баар эсвэл sheet толгой: **Үлдэгдэл ₮X**
- «Цэнэглэх» том товч (QPay)
- Үлдэгдэл 0: «Авах» идэвхгүй, banner «Кредит цэнэглэнэ үү»

### D2 Хүлээн авах (газрын зураг төв)
- Газрын зурагт pickup цэг + зай
- Sheet: зай/мин + **нийт үнэ** (зорчигчийн үнэ)
- Ногоон «Авах» 72px / «Татгалзах»
- Кредит дууссан бол «Авах» disabled

### D3 Зорчигч руу явж байна
- Маршрут pickup хүртэл
- Sheet: зорчигчийн утас → Залгах; «Зорчигч авсан» 72px; «Цуцлах»

### D4 Аялалд
- Очих цэг хүртэлх маршрут
- «Дуусгах» 72px

### D5 Аялал дууссан (орлого)
- Том: **Таны орлого ₮Y** (нийт − 10%)
- Жижиг muted: «Шимтгэл 10% · ₮Z»
- Хэрэв бэлэн: «Кредитээс −₮Z» + шинэ үлдэгдэл
- Хэрэв QPay: «QPay-ээс шимтгэл суутгасан»
- «Болсон» → D2

## Админ (товч UI тэмдэглэл)
- Тариф: суурь + ₮/км
- Шимтгэл % (default 10)
- Жолоочийн кредит гараар засварлах
- Машины дугаар шалгах
